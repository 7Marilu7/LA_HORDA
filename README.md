# LA HORDA

Videojuego web de plataformas en 2D inspirado en la película *Fragmentado*, desarrollado con HTML, CSS y JavaScript.

## Descripción

LA HORDA es un videojuego web en el que acompañas a Kevin a través de una aventura dividida en seis niveles, cada uno inspirado en una de sus personalidades. El jugador deberá superar obstáculos, saltar entre plataformas y llegar a la meta antes de que se agote el tiempo.

## Funcionalidades

- Videojuego de plataformas en 2D.
- Seis niveles con diferentes escenarios y desafíos.
- Personajes y animaciones para cada nivel.
- Sistema de movimiento horizontal y salto.
- Controles mediante teclado y dispositivos táctiles.
- Sistema de vidas y temporizador.
- Transiciones entre niveles.
- Elementos interactivos y obstáculos.
- Interfaz adaptable a dispositivos móviles.
- Presentación de personajes y descripción de la historia.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Canvas API

## Instalación local

1. Clona este repositorio:

```bash
git clone https://github.com/7Marilu7/LA_HORDA.git
```

2. Accede a la carpeta del proyecto:

```bash
cd LA_HORDA
```

3. Abre el archivo `index.html` directamente en tu navegador.

También puedes utilizar la extensión **Live Server** de Visual Studio Code para ejecutar el proyecto en un servidor local.

## Instrucciones de juego

**Movimiento horizontal:**
- A o flecha izquierda: moverse a la izquierda.
- D o flecha derecha: moverse a la derecha.

**Salto:**
- Barra espaciadora.
- W o flecha arriba.

**Dispositivos móviles:**
- Utiliza los controles táctiles que aparecen dentro del área de juego.
